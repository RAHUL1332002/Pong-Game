# Pong Game 🏓

A beginner Python project that recreates the classic two-player Pong game using Turtle graphics.

## Features
- Two-player gameplay
- Keyboard-controlled paddles
- Ball movement and wall bouncing
- Score tracking

## Technologies
- Python
- Turtle graphics

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

## Controls
- Right paddle: Up and Down arrow keys
- Left paddle: W and S keys
